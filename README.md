# 📊 Amazon Sales Analysis using SQL & Power BI

## 📌 Project Overview

This project analyzes Amazon sales data using SQL for data extraction and analysis and Power BI for creating an interactive dashboard. The goal is to uncover business insights related to sales performance, customers, products, payments, and shipping.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Identify top-selling products and categories.
- Measure customer purchasing behavior.
- Evaluate payment success rates.
- Analyze shipping performance and return rates.
- Build an interactive dashboard for business decision-making.

3. Open the Power BI (.pbix) file.
4. Refresh the data if required.
5. Explore the dashboard using filters and slicers.

## 💡 Business Insights

- Electronics generated the highest revenue.
- Credit Card was the most preferred payment method.
- Return rates were higher in some product categories.
- A small percentage of customers generated a large share of revenue.
- Monthly sales showed seasonal trends.
